# SmartFactory 3D MES

Учебная диспетчерская механического цеха с интерактивной 3D-моделью и имитацией производственного потока. Все данные демонстрационные.

## Возможности

- Проходная паллетная линия: точение, фрезерование, сверление, контроль, упаковка и приёмка.
- Выбор оборудования, приближение камеры и разрез станка.
- Показатели смены, телеметрия, очереди и журнал событий.
- Сценарии перегрева, замедления контроля и отклонения размера.
- Действия оператора для восстановления нормальной работы.

## Запуск локально

Из корня проекта:

```sh
python -m http.server 4173 --directory dist
```

Откройте http://localhost:4173. Нужен браузер с поддержкой WebGL2. Сборка и серверная база данных не требуются.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**. Workflow `.github/workflows/pages.yml` публикует только `dist` после изменения сайта в ветке `main`. Также доступен ручной запуск через **Actions → Deploy SmartFactory MES → Run workflow**.

Адрес после успешной публикации: https://andrewthepython2018.github.io/mes/

## Технологии

JavaScript, HTML/CSS и Three.js. Библиотеки находятся в `dist/vendor`; лицензия Three.js сохранена в `dist/vendor/LICENSE`.
